### Critical security requirements

The application must NEVER:

- Request users' seed phrases.
- Collect private keys.
- Upload private keys to the backend.
- Store recovery phrases in the database.
- Store decrypted wallet credentials.
- Secretly initiate wallet transactions.
- Execute transfers without explicit user authorization.
